**Заголовок: "Ошибка при обработке значения None в функции trim"**

**ID: BUG-001**

**Описание: Функция trim выбрасывает AttributeError, когда входное значение None**

**Шаги для воспроизведения:**
1. Откройте файл `string_utils.py`.
2. Вызовите функцию `trim` с параметром `None`.
3. Наблюдайте за ошибкой "AttributeError: 'NoneType' object has no attribute 'startswith'".

**Ожидаемое поведение:**
Функция должна корректно обрабатывать значение None, например, выбрасывая исключение TypeError.

**Фактическое поведение:**
Функция выбрасывает AttributeError, что приводит к сбою.

**Приоритет:**
Средний

**Окружение:**
- Операционная система: Windows 11
- Версия Python: 3.14.7
- Версия библиотеки: текущая

**Заголовок: Некорректная работа функции проверки наличия символа в строке**

**ID: BUG-002**

**Описание:**
Функция проверки наличия символа в строке возвращает True, когда ожидается False.

*Шаги для воспроизведения:*
1. Запустить тест test_contains_negative с входными данными "", "", False.
2. Обратите внимание, что тест завершается с ошибкой AssertionError, 
так как функция возвращает True вместо ожидаемого False.

**Ожидаемое поведение:**
Функция должна возвращать False, если искомый символ отсутствует в строке.

**Фактическое поведение:**
Функция возвращает True, даже если символ отсутствует, что приводит к провалу теста.

**Приоритет: Средний**

**Окружение:**
- Операционная система: Windows 11
- Версия Python: 3.14.7
- Версия библиотеки: текущая

**Дополнительная информация:
Тест ожидает, что функция будет возвращать False для пустой строки или строки,
не содержащей искомый символ. Аналогично тест ведет себя с входными данными: ('jocker', '', False) и ('04 апреля 2023', '04', False)

**Заголовок:** Некорректная работа функции удаления символов из строки

ID: BUG-003

**Описание:**
Функция удаления символов из строки возвращает некорректный результат. 
Ожидаемое поведение при удалении подстроки "Sky" из "SkyPro" — получение "Pro", 
однако функция возвращает "SkyPro", что свидетельствует о том, что подстрока не была удалена.


**Шаги для воспроизведения:**

1. Запустить тест test_delsymb_negative с входными данными: строка "SkyPro", 
подстрока для удаления "Sky".
2. Обратите внимание на результат выполнения теста — AssertionError, 
поскольку возвращаемое значение "SkyPro" не совпадает с ожидаемым "Pro".


**Ожидаемое поведение:**
Функция должна удалять все вхождения подстроки "Sky" и возвращать строку "Pro".

**Фактическое поведение:**
Функция возвращает исходную строку "SkyPro" без изменений.

**Приоритет:** Средний

**Окружение:**
- Операционная система: Windows 11
- Версия Python: 3.14.7
- Версия библиотеки: текущая

**Заголовок: Ошибка при удалении символа None из строки**

ID: BUG-006

**Описание:**
Функция удаления символа вызывает ошибку типа TypeError, когда в качестве символа для удаления передается значение None. Ошибка возникает, так как метод index() в Python ожидает строку в качестве аргумента, а не None.

**Шаги для воспроизведения:**

1. Запустить тест test_delsymb_negative с входными данными: строка "04 april 2026", 
символ для удаления None.
2. Обратите внимание на возникновение ошибки TypeError: index() argument 1 must be str, not None.



**Ожидаемое поведение:**
Функция должна корректно обрабатывать случай, когда символ для удаления None, 
либо выбрасывая более конкретное исключение, либо игнорируя такие вызовы.


**Фактическое поведение:**
Функция вызывает ошибку TypeError, что приводит к сбою теста.

**Приоритет:** Средний

**Окружение:**
- Операционная система: Windows 11
- Версия Python: 3.14.7
- Версия библиотеки: текущая

**Дополнительная информация:**
Убедитесь, что функция корректно обрабатывает случаи, 
когда в качестве символа для удаления передается None.
